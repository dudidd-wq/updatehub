**מרכז עדכונים אוטומטי למחשב Windows** — מעדכן את כל רכיבי המחשב בלי כלי יצרן, עם דף סטטוס חי בעברית (פס התקדמות, אחוזים לכל פריט, יומן תמציתי / מפורט / VERBOSE) ותזמון שבועי.

גרסה 1.6 · Windows 10/11 · Windows PowerShell 5.1 · בלי התקנות נוספות.

## מה מתעדכן

Windows Update (כולל אופציונליים ודרייברים) · דרייברים וקושחה מקטלוג Microsoft לפי מזהה חומרה · NVIDIA · Microsoft 365 · winget · Microsoft Store · מודולי PowerShell · pip · תוספי VS Code · WSL · Chocolatey / Scoop / npm · Defender · בדיקת תקינות התקנים.

**וגם את עצמו:** מגרסה 1.6, UpdateHub בודק בכל ריצה אם יש לו גרסה חדשה כאן ב-GitHub ומתקין אותה. אפשר לבחור בדשבורד: אוטומטי / הודעה בלבד / כבוי. גרסה מותקנת רק אם היא חתומה במפתח שלא נמצא ב-GitHub, כך שגם השתלטות על החשבון לא מאפשרת להפיץ קוד.

## התקנה

1. **Code → Download ZIP**, ואז קליק ימני על ה-ZIP → מאפיינים → "בטל חסימה" (Unblock).
2. לחלץ לתיקייה **בתוך הפרופיל** (למשל `Documents\UpdateHub`). לא לשורש הכונן, כמו `C:\Tools`.
3. להפעיל את `run.bat` ולאשר הרשאות מנהל. הוא מתקין ל-`C:\Program Files\UpdateHub` ויוצר קיצור דרך "UpdateHub".
4. מעכשיו פותחים רק מקיצור הדרך. בפעם הראשונה כדאי להתחיל ב"סריקה בלבד".

המדריך המלא נמצא ב-[`README.txt`](README.txt): הגדרות, נתונים, פרטיות, הסרה ומגבלות.

## בטיחות ואבטחה בקצרה

- אף פעם לא מוריד גרסה. דרייבר מותקן רק אם הוא חתום על ידי Microsoft ומתאים בדיוק לחומרה.
- קושחה מותקנת רק אחרי השוואה לגרסה שרצה בפועל (ESRT), רק כשהמחשב מחובר לחשמל ויש מספיק סוללה, ועם השהיית BitLocker לאתחול אחד.
- רץ רק מ-Program Files. הדף נגיש רק מהמחשב עצמו, דרך מפתח חד-פעמי.
- כלים אישיים (pip, VS Code, Scoop, npm) רצים בהרשאות משתמש רגילות, לא כמנהל.
- נקודת שחזור, נעילת תיקיית נתונים למנהלים בלבד, מגבלות זמן לכל תהליך, ומניעת שינה בזמן ריצה.
- עדכון עצמי: `release.signed` חתום ב-RSA-3072 (המפתח הציבורי קבוע ב-`engine.ps1`), SHA-256 לכל קובץ, רק גרסה חדשה יותר, בדיקת תחביר לפני החלפה, החלפה אטומית עם שחזור, ו-`settings.json` לא נוגעים בו.

## בדיקה

גרסה 1.5 עברה 6 סבבי בחינה חיצונית ו-5 סבבי ביקורת אבטחה בלתי תלויים, וגם בדיקות XSS בדפדפן (קוד 9.8, אבטחה 9.7).
העדכון העצמי של 1.6 עבר 3 סבבי בחינה חיצונית נוספים, ובדיקה מקצה לקצה על Windows PowerShell 5.1 אמיתי (13/13 תרחישים: התקנה, שחזור אחרי כשל, תיקון קובץ, חתימה מזויפת, גרסה ישנה). **ציון 1.6: קוד 9.7/10, אבטחה 9.6/10.**
לפני הפעלת התזמון השבועי מומלצת ריצה ראשונה מפוקחת, כמתואר ב-README.txt.

## פרסום גרסה (למתחזק)

1. מעדכנים את הקבצים ואת מספר הגרסה בשלושה מקומות: `$script:AppVersion` ב-`engine.ps1`, `$ServerVersion` ב-`server.ps1`, ו-`<meta name="updatehub-version">` ב-`updater.html`.
2. בדיקה על Windows (PowerShell 5.1, כמנהל): `tools\Test-SelfUpdate.ps1`. היא מריצה את העדכון העצמי מקצה לקצה בתיקייה זמנית, מול שרת מקומי ומפתח חד-פעמי, בלי לגעת בהתקנה.
3. `python3 -I tools/sign_release.py sign --repo . --version X.Y --key <קובץ המפתח הפרטי> --notes "מה חדש"`. הכלי מסרב אם הגרסה לא חדשה מהגרסה שפורסמה, או אם המפתח אינו המפתח שהעותקים המותקנים סומכים עליו.
4. commit של הקבצים יחד עם `release.signed`, push של ענף השחרור `vX.Y` (`git push origin HEAD:refs/heads/vX.Y`) **ואחריו** של `main`, ואז `sign_release.py verify-remote --repo . --version X.Y`. העותקים המותקנים מורידים את הקבצים מ-`<repo>/vX.Y/...`, כתובת שעובדת גם לענף וגם לתגית בשם הזה.

המפתח הפרטי נמצא רק במחשב של המתחזק, והחתימה נעשית שם. הוא לא נכנס לריפו ולא יוצא מהמחשב. מספרי גרסה רק עולים.

## דרישות

- Windows 10/11 עם Windows PowerShell 5.1 ומשתמש עם הרשאות מנהל.
- לא רץ תחת Constrained Language Mode (WDAC / Smart App Control) או מדיניות AllSigned. במקרה כזה מוצגת הודעה ברורה.
